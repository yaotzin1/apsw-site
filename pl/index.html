claude-code
Wypisz w stopce „z wielu”, gdy źródło nie podaje sumy. Arytmetyka stron bez zmian.

                      
antigravity
Zgoda co do stopki. Zastrzeżenie: krótka ostatnia strona dowodzi końca, więc wtedy grid powinien podać prawdziwą sumę.

                    

                    
  footer.total
- claude:      total ?? "of many"
+ antigravity: lastPage.length < pageSize ? offset + lastPage.length : "of many"

                    
Obie propozycje zapisane. Kodu jeszcze nie ma.

            02DOWÓD PRACY W OPEN SOURCE
            
          
            Najpierw budujemy własne silniki
            
          
            Oba projekty mają licencję MIT. Przeczytaj kod, zanim przeczytasz naszą ofertę.
            
        
            

        
            
          
            
            
            
              
            Indaba
            
              
            @indaba/engine · v0.1.0-alpha.5 · MIT · TypeScript, Node 22+
            
            
            
            
            Pozwól agentom się spierać. Wdrażaj to, co uzgodnią.
            
            
            
            
              npx indaba@next validate workflow.ai.yml
              
            
            
            
              
              
            • Zadeklarowany graf kroków za strażnikami kodu wyjścia. Krok przechodzi, gdy polecenie kończy się kodem 0, a nie gdy model tak twierdzi.
              • 
              
            • Rada agentów uzgadnia wynik przez wzajemną weryfikację. Gdy nie dojdą do zgody, decyduje człowiek jako arbiter.

            • Uruchamia Claude Code, Codex, Gemini, Cursor lub Antigravity w jednorazowych worktree gita.
              • 
              
            • Ślady OpenTelemetry GenAI. Każdy token i dolar jest policzony, nigdy zmyślony.
              • 
            
            
            
            Wydanie podglądowe. API nie jest stabilne poniżej wersji 1.0.

            03STANDARD INŻYNIERSKI
            
          
            Jeden plik reguł jest ważniejszy niż każdy prompt
            
          
            Zespół, który promptuje z przyzwyczajenia, dostaje inny kod od każdego inżyniera. My utrzymujemy jeden plik. Wszystko, co czyta agent, jest z niego generowane, a CI nie przechodzi, gdy kopia się rozjedzie.
            
        
            

        
            
          
            
            workflow.ai.yml
            jedyne źródło reguł
          
            
          
              
            
            • generujeAGENTS.mdładowany przez każdego agenta czytającego AGENTS.md
              • 
            
            • generujeCLAUDE.mdpunkt wejścia Claude Code
              • 
            
            • generujeGEMINI.mdpunkt wejścia Gemini
              • 
            
            • egzekwuje.githooks/pre-commitbramki działają, zanim powstanie commit
              • 
            
            • egzekwujeCI · drift checkte same bramki przy każdym pull requeście
              • 
          
            
          
            
            
            
            $ ci: instructions-drift --check   → exit 0
            
            
            Zsynchronizowane. Każdy wygenerowany plik zgadza się z plikiem reguł.
            
          
            
        
            

        
              
          
            1. 1
              Graf z bramkami
              O wyniku decydują strażnicy: polecenia, diffy gita, sprawdzenia plików. Błąd ponawia tylko wskazany krok z ostatnim błędem. Pełna historia nigdy nie zaśmieca kontekstu.
              2. 
          
            2. 2
              Rada, nie chór
              Kilka modeli weryfikuje nawzajem ten sam diff, aż osiągną kworum.
              3. 
          
            3. 3
              Egzekwowane, nie tylko zapisane
              CI od razu blokuje zmiany, gdy instrukcje w repozytorium przestają się zgadzać z workflow.ai.yml.
              4. 
          
            4. 4
              Weryfikowane tam, gdzie pęka
              Testy dymne na zbudowanych pakietach, audyty paczek i bramki bezpieczeństwa blokują złe commity przed przeglądem człowieka.
              5. 
        
            
      
            
    
            

    
    
            
      
            
        
            
          
            04MODEL DOSTAWY „KLIN ARCHITEKTA”
            
          
            Precyzja architekta. Skala partnera.
            
          
            Na początku architektura od głównego architekta. Dalej elastyczne zespoły inżynierskie.
            
        
            

        
            
          
            Samodzielny freelancer
            Duże umiejętności, brak mocy przerobowych. Projekt staje, gdy staje jedna osoba.
            
          
            Tradycyjna agencja
            Moce są, ale start jest powolny, po drodze stoją opiekunowie klienta, a kodu nikt nie zweryfikował.
            
          
            APSW Labs
            Jeden architekt ustala kontrakty i bramki. Moce przerobowe dochodzą za nimi.
